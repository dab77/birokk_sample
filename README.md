# Макет главной страницы birokk.ru

Статическая страница для GitHub Pages: `index.html` + `images/`.

1. Загрузите всё содержимое в корень репозитория.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
3. Страница откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
